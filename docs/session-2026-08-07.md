## 3. 修复 IconFontConfig 类型声明错误

### 问题
使用 `import * as iconfonts from '@nutui/icons-react-taro'` 后访问 `iconfonts.IconFontConfig.data` 报 TypeScript 错误。

### 根因
`vite.config.dts.ts` 的 `afterBuild` 钩子中，手动追加的类型声明写成了：
```ts
export declare class IconFontConfig { [key: string]:any }
```
但实际运行时 `IconFontConfig` 是一个 `const` 对象 `{ name, data, style }`，类型不匹配导致 TS 报错。

### 修复
将两个包的 `vite.config.dts.ts` 中的类型声明改为：
```ts
export declare const IconFontConfig: { name: string; data: Array<{ name: string; nameEn: string; icons: string[] }>; style: Array<{ name: string; nameEn: string; icons: Array<{ name: string; [key: string]: string }> }> };
```

涉及文件：
- `packages/icons-react-taro/vite.config.dts.ts`
- `packages/icons-react/vite.config.dts.ts`
